Consulta processual pública para TJSP, TJAL e TJCE

Aplicação web em Python que consulta portais públicos de tribunais, extrai os campos disponíveis e exibe o resultado em uma interface simples.

O que a interface faz

01

Consulta por número CNJ

Você informa o número do processo no padrão CNJ e a aplicação consulta os portais públicos suportados para buscar os dados disponíveis.

02

Exibição dos dados coletados

Os dados extraídos são organizados em telas com informações básicas, partes e movimentações, quando o portal consultado disponibiliza esses campos.

03

Uso responsável

O projeto trabalha com dados públicos e a documentação discute limites de coleta, proteção de dados e uso ético de scraping em portais judiciais.

Por que essa interface existe

📍

Heterogeneidade de Portais

Cada tribunal organiza sua consulta de forma diferente, o que torna a navegação manual mais trabalhosa.

⏱️

Acesso Fragmentado

Quem precisa acompanhar um processo pode ter de consultar mais de um portal e repetir a mesma busca em cada um.

🔗

Falta de Padronização

A apresentação dos campos varia entre tribunais, então a interface padroniza apenas a visualização do que foi extraído.

🚪

Barreira de Acesso

O formulário reduz o esforço de navegação para quem quer consultar um processo pelo número CNJ.

Informações Disponíveis

Os campos abaixo dependem do que o portal de origem disponibiliza na página consultada

📋

Dados Básicos

  • Classe processual
  • Área do direito
  • Assunto
  • Data de distribuição
  • Valor da ação
  • Juiz responsável
👥

Partes Processuais

  • Nomes dos envolvidos
  • Tipo de participação
  • Advogados informados no portal
📅

Movimentações

  • Data da movimentação
  • Descrição da movimentação
  • Histórico exibido no portal

Limitações atuais

🌐

Dependência dos portais

Se o portal do tribunal estiver lento, instável ou fora do ar, a consulta pode falhar ou demorar mais do que o esperado.

🧩

Formato variável

Nem todos os tribunais expõem os mesmos campos com a mesma consistência, então algumas consultas podem retornar menos dados.

⏳

Tempo de resposta

A aplicação faz consulta online ao tribunal de origem; por isso, o tempo de resposta depende do portal consultado.

📖

Escopo do projeto

O sistema é uma prova de conceito para busca e leitura de dados processuais, não um repositório oficial nem uma API judicial universal.

Observação: o Jus Crawler exibe apenas o que conseguir extrair dos portais públicos suportados. Quando a consulta falhar, a interface mostra a mensagem de erro retornada ou uma indicação de indisponibilidade.
